HOW TO PUBLISH TO THE EXISTING GITHUB PAGES SITE
1. Download and unzip this package.
2. Open the existing repository: https://github.com/drarkasaha/drarkasaha-website
3. Keep a backup of the current index.html before replacing anything.
4. Upload the new index.html and the entire assets folder to the repository root (same level as index.html).
5. Commit the changes to the main branch.
6. GitHub Pages should redeploy automatically. Your existing domain/DNS settings do not need to be changed for this content update.

No framework or build step is required. This is a static HTML website.
